# LOFTGROOT

Сайт LOFTGROOT — мангальные комплексы в стиле LOFT, Алматы.

## Перед первым запуском

- **Node.js 24**, затем `npm install`.

## Git

| Команда | Что делает |
|---|---|
| `git pull` | Скачать свежие изменения из репозитория на GitHub |
| `git push` | Отправить свои коммиты на GitHub |

## Работа на компьютере

| Команда | Что делает |
|---|---|
| `npm install` | Поставить зависимости — после первого скачивания и после изменений в `package.json` |
| `npm run dev` | Запустить сайт на компьютере: http://localhost:5173 |

## Проверка и сборка

| Команда | Что делает |
|---|---|
| `npm run typecheck` | Проверить код на ошибки |
| `npm run build` | Собрать сайт в папку `dist` |
| `npm run preview` | Открыть собранный сайт на компьютере |

## Выкладка на хостинг

Собрать сайт командой `npm run build` и залить содержимое папки `dist` на хостинг.

## Фильм и картинки

Работают только при локальной папке `docs` с исходниками. Для запуска и сборки сайта не нужны — готовые картинки уже лежат в проекте.

| Команда | Что делает |
|---|---|
| `npm run film` | Собрать кадры фильма из роликов и стоп-кадров |
| `npm run seams` | Проверить стыки роликов фильма |
| `npm run stills` | Пересобрать стоп-кадры, галерею и `og.jpg` |
